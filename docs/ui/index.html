アイコンの線引き

意味が世界共通の操作は絵、このアプリ固有の概念は文字。 戻るボタンの意味は説明しなくても通じるが、「教材」「復習」「要復習」は Revia を使って初めて意味を持つ。理由は決定 28。

戻る 章を開く 選び直す 足す 設定 メニュー 削除 取っ手 撮る 手で作る 外す

上の絵は本物の Lucide（lucide@0.263.1 を CDN から読み込む。読み込めなければ、似せて描いた控えが出る）。 ナビの「教材」「復習」は文字のまま。

教材を追加する流れ ： 2教材一覧→ 3方法の選択→ 4目次の写真→ 5解析中→ 6確認・編集→ 7完了→ 8教材詳細 手動なら ： 3方法の選択→ 9教材名の入力→ 6確認・編集（空から）
